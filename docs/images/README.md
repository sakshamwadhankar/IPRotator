exact name below, then remove the `<!--` and `-->` around its link in `README.md`.

| File | What it should show |
|---|---|
| `setup.png` | The `setup.bat` window after a successful run, with all six steps showing `[OK]`. |
| `start.png` | The `start.bat` window after answering both questions, including the green "Running in background..." line. |
| `status.png` | The `status.bat` window while running: interval, server in use, current IP, next switch and log lines. |

**Before you take a screenshot, blur or crop out your real IP addresses, your
Windows username in any file paths, and anything else personal.**
